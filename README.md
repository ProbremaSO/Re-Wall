# Re:Wall

A GUI wallpaper manager for KDE Plasma.

## Features

- Manage and organize wallpapers easily
- Intuitive KDE Plasma integration
- Quick wallpaper switching
- Second Plan execution(Tray exec)
- In App/Gui customization
- Auto-Pause in Fullscreen 

## Installation

Exec AppRun, Auto install functionality, the python script installs the plugin and you ony have to set up it on Kde Wallpaper --> type off wallaper --> and select Re:Wall Engine

## Usage

In pratice, is a auto-installer and gui for a kde wallpaper plugin(as well Smart video wallpaper Reborn)
